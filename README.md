# SignalDesk

Financial news and social conversations, translated into structured risk signals and a simulated stock index.

Built for the Delhi Technological University financial risk hackathon. Implements the unified NLP risk engine and Module A: tactical index rebalancing.

## Run locally

Requires Node.js 22.13+.

```sh
npm install
npm run dev
```

Open http://localhost:5173. The API runs on port 3001.

## Development stages

1. App foundation
2. NLP risk engine
3. Source ingestion and index rebalancing
4. Interactive dashboard
5. Validation and documentation

This is a research prototype using a mock portfolio, not a trading service.
